JavaScript Utility Functions

Overview

This repository contains multiple JavaScript functions that implement various algorithmic solutions and polyfills. Each function is designed to be efficient, readable, and reusable.

Features

Find the first non-repeating character in a string

Move all zeros to the end of an array

Find duplicate elements in an array

Debounce function for optimizing event listeners

Polyfills for map, filter, reduce, call, apply, and bind

Implement closures in JavaScript

Custom Promise polyfill

Fibonacci sequence generator

Functions

How to Use

Clone this repository:

git clone https://github.com/Shivamxeric/javascript-utilities.git

Navigate to the project directory:

cd javascript-utilities

Open the project in your preferred code editor and run the functions using Node.js or in the browser console.
